# Autoclicker Project

This directory contains a complete autoclicker application with statistical distribution controls.

## Quick Start

### For End Users
1. **Download**: Clone this repository or download the autoclicker folder
2. **Install Python Dependencies**: `pip install -r requirements.txt`
3. **Run**: `python main.py`
4. **Build Executable**: Run `build.bat` (Windows) or see COMPILE_INSTRUCTIONS.md

### For Developers
- `main.py` - Main application with GUI
- `requirements.txt` - Python dependencies
- `test_distributions.py` - Statistical distribution testing
- `test_gui.py` - Simple GUI test version
- `build.bat` - Windows build script
- `README.md` - Comprehensive documentation
- `COMPILE_INSTRUCTIONS.md` - Detailed build instructions

## Features

✅ **Cross-platform GUI** (Windows, macOS, Linux)  
✅ **Statistical distributions** (Gaussian & Log-normal)  
✅ **Configurable delays and timing**  
✅ **Optional hotkey support**  
✅ **Graceful degradation** with missing dependencies  
✅ **One-click executable compilation**  
✅ **Comprehensive documentation**  

## Dependencies

- **Required**: Python 3.7+, tkinter (usually included)
